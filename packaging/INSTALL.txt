TinyTodo

安装时默认勾选“开机自启动”和“创建桌面快捷方式”，可取消。
默认安装位置：%LOCALAPPDATA%\Programs\TinyTodo
启动时显示任务窗口，猫猫是否出现按设置中的显示规则决定。
从托盘菜单选择“退出”可完全关闭程序。

可在 Windows“设置 → 应用”中卸载。卸载会移除程序、自启动和安装器创建的快捷方式。卸载时默认勾选“同时清理任务文件和备份”；取消勾选可保留数据。清理包含已登记的自选数据目录，删除后不可恢复。
升级时直接运行新版安装包覆盖安装，无需先卸载。已有任务与自选数据目录会继续读取；覆盖安装不会清理任务文件。

3.6.0 及以后版本使用任务数据格式 2；旧版 3.5.x 无法读取此格式。

设置中可连接 GitHub 私有仓库。启动自动 Pull，任务更新自动 Push，也可手动操作。Token 环境变量名留空时使用本机已有 Git 登录；指定名称时从 Windows 环境变量读取 token。卸载清理本机数据不会删除云端仓库。
